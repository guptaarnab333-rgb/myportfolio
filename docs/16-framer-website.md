## Project

A marketing-style website built in **Framer**, anchored around the headline:

> **We transform actions into understanding.**

The site presents itself as belonging to an insight-oriented studio for businesses — heavy on motion, hover states, and interactive demos that show off Framer's component-driven capabilities.

---

## Sections

### 1. Landing Page
- Bold purple/violet gradient hero
- Tagline: *"We transform actions into understanding"*
- CTA button
- Subtle abstract violet shapes as background ornament
- Strong, type-led hierarchy with generous whitespace

### 2. Clean & Minimal Layout
- Showcases the studio's information architecture: how content is laid out without clutter
- "Insight-oriented studios for businesses" — card-based content modules
- Two-card grid showing case-study-style entries

### 3. Interactive Interface
- Demonstrates **hover-state mockups** — cards reveal additional information on hover
- A featured **"Drag any item"** interactive demo with a 3D star element — users can drag a graphical element across the screen, showing real-time response
- Highlights the interactivity that Framer enables out-of-the-box

### 4. Closing — Thank You

## Visual Language

| Element | Detail |
|---|---|
| **Palette** | Bold violet / purple as the dominant brand colour, with white surfaces and dark text |
| **Typography** | Sans-serif, large display sizes, tight line height for impact |
| **Whitespace** | Generous — the layouts breathe |
| **Motion** | Hover reveals, drag-and-drop interactivity, smooth transitions |

---

## What It Demonstrates

1. **Tool fluency** — Framer is a specific tool with its own design idioms; building a Behance-quality presentation in it shows command of the platform's components, variants, and interactions
2. **Interaction sensibility** — drag, hover, and reveal states aren't just decorative; they're used to communicate the studio's value prop (interactivity = engagement)
3. **Visual confidence** — a single bold colour applied with restraint reads as more premium than a multi-colour palette would
