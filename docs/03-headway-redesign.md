## What Is Headway?

A book summary app that delivers knowledge in bite-sized formats.

## Why It Needs a Redesign

- Outdated visual style
- Limited customization
- Limited language support (English-only)
- Limited engagement
- Limited audiobook quality

## Purpose of the Redesign

The Headway redesign aims to enhance **accessibility, engagement, and personalization** for users. By incorporating additional language support, customizable reading lists, and enhanced features, the redesign aims to make Headway a more dynamic, engaging, and flexible learning platform.

## 01 Discover Phase

### User Research
Identified frequent complaints from existing Headway users:
- Misleading marketing claims
- Lots of intro cards in onboarding
- Confusing rating systems
- Long subscription processes
- Hard-to-find features in the app
- Need for highlight/note features in summaries
- Want a more customized reading experience

### Competitor Analysis

| Competitor | Notable Strengths |
|---|---|
| **Blinkist** | Strong active users, in-depth content, premium reading experience |
| **deepstash** | Curated insight cards, recommendations |
| **Shortform** | High-quality summaries, robust reading depth |
| **Headway (current)** | Categories tagging, free trial entry |
| **Google Play Books** | Vast catalogue, integration into the Play ecosystem |

### Feature Comparison Matrix
Audiobook · Streaks · Categories · Infographics · Stories · Community · Reading List · Sharing · Notes — compared across competitors with check/cross matrix.

### User Survey Findings
Pie chart insights:
- Majority of users use a tablet or phone (24+ inches not common)
- Most respondents are accustomed to reading
- Multiple language support (especially Hindi) is highly desired
- Users want recommendations
- Distractions are common: notifications, real-life interruptions
- Short summaries preferred over long ones by most

**Headline finding:** Users want simple reading sessions, multi-language support (Hindi), and ease of access to summaries.

## 02 Define Phase

### User Personas

#### Aanya Sharma
- Younger user, lifestyle-focused
- **Apps:** Instagram, ASOS, Netflix

**Frustrations:**
- Confusing Login — multiple options without clear hierarchy; no "guest" or "explore" option
- Overwhelming Introduction — too many intro cards leading to user fatigue; unnecessary/generic cards; vague explanations
- Lengthy process — unclear impact of interest selection on content; pushy claims before demonstrating app value

#### Rajesh Verma
- Older user, value-focused
- **Apps:** YouTube, Spotify, Facebook

**Frustrations:**
- Poor Reading Experience — unclear summary length; confusing rating/review system; poor readability (font, formatting, size); limited reading-mode color options; lack of visuals to break up text; lack of playback-speed control for audio summaries
- Limited Post-Reading Interaction — lack of actionable insights/takeaways; no tools for highlighting, note-taking, or questions; difficulty finding related content

### User Journey Maps
Built for both personas — showing entry, frustration peaks, drop-off points across login → onboarding → reading flow → post-read.

### Problem Statement

> Headway's app has user experience issues with its UI and navigation, making it difficult for users to find information or features. This is causing frustration and reducing engagement, impacting overall user satisfaction and retention.

### Five Core Challenges
1. **Complicated navigation**
2. **Lengthy onboarding**
3. **Interruptions from streaks**
4. **Restricted content discovery**
5. **Lack of customization options**

## 03 Ideate Phase

### Old vs New Features Comparison

| Old Features | New Features |
|---|---|
| Only text size can be adjusted | Text can be read in **4 fonts** |
| Only dark and light background | **Light, Dark, Beige and Black** background |
| Audiobook feature | + **White noise feature** (rainfall, gentle waves) |
| No reviews or ratings | **Rating & Reviews** of the book section |
| Library section without text customization | **Custom reading list** section |
| Only English language support | **Multiple languages** |
| Translate prompt | **Dictionary feature** |
| Streak prompt | **Animation for streaks** |
| — | **Annotation sharing** |

### Feature Prioritization & Brainstorming

1. **Reduce the onboarding screen** — simplify app introduction; potentially improve UX and engagement for new users
2. **White noise option** — ambient sounds (rainfall, gentle waves) to help users focus while reading or listening
3. **Rating & reviews of the book** — adds ratings/reviews section so users can see recommendations and assess summary quality
4. **Background color adjustment while reading** — enhances customization, meets user preferences, improves reading experience
5. **Custom reading list section** — allow users to group favorite summaries into folders for easy access
6. **Recommendations of books in multiple languages** — diverse selection, suits language preferences, broadens reading horizons
7. **Add a dictionary** — instant definitions, enhances comprehension and reading experience
8. **Pop notification of streaks** — motivates users by celebrating progress and milestones
9. **Annotation sharing** — share notes and highlights; promotes collaboration, learning, richer reading

### New Information Architecture
Restructured app tree with new home → discover → reading → profile flows showing repositioned features and added paths.

## Outcome & Reflection

- Improved navigation
- Deeper customization (fonts, colors, reading modes)
- Richer engagement features (white noise, animations, ratings)
- Multi-language access
- Community-oriented annotation sharing

**Constraints noted:** Limited time for testing; would benefit from further iteration cycles.
