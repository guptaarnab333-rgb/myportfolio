## Project Title
**Rebranding of Kubocare**

A comprehensive rebranding exercise covering visual identity, messaging, and applied collateral for a healthcare brand.

---

## Sections Delivered

### 1. Moodboard
Visual reference set establishing the brand's emotional tone — likely clean, clinical, trustworthy, warm (typical healthcare references).

### 2. Brand Name
Rationale and treatment for the **Kubocare** name as the verbal mark.

### 3. Wireframe Design
Layout-level wireframes for the application of the brand (likely website and/or mobile app).

### 4. Visual Identity
- **Wordmark with M-style monogram** — geometric blue/teal forms
- Distinctive "M"-shaped mark that reads as both letterform and as healthcare-adjacent geometry (could read as a heartbeat, a fold, a bridge)

### 5. Typography
Type system — primary and secondary typefaces specified for headings, body, and applied use.

### 6. Color Palette
- **Cool blues** dominate (trust, healthcare convention)
- **Teal accents**
- **Cream/off-white** background base
- The palette signals *reliable, modern, calm*

### 7. Brand Messaging
Verbal identity — likely a tagline + brand voice principles + key messages applied across touchpoints.

### 8. Website Mockup
Marketing/product website design applying the new identity.

### 9. Landing Page
A dedicated landing-page mockup — likely the primary marketing surface.

### 10. Application Design
Mobile application screens — likely a patient or care-management app.

### 11. Social Media Applications
The brand applied to social media posts, profile imagery, and feed grids.

### 12. Real-World Embodiment
Mockups of the brand in context — packaging, signage, business cards, environmental graphics, or similar physical applications.

### 13. Brand Guidelines
A guidelines document covering logo usage rules, color reproduction, type pairings, spacing, do's and don'ts.

---

## What This Project Shows

1. **End-to-end brand thinking** — not just a logo, but the full system: visual identity → application → guidelines
2. **Healthcare-appropriate restraint** — cool palette, clear monogram, no decorative excess
3. **Multi-surface application** — web, app, social, real-world — proves the system holds up across contexts
4. **Wireframe → mockup discipline** — wireframes before visual design indicates a structured process
